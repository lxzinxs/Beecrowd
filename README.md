# 🐝 Beecrowd Java Solutions

Este repositório é dedicado à organização e acompanhamento da resolução de problemas da plataforma **Beecrowd** (antigo URI Online Judge) utilizando a linguagem **Java**.

O objetivo principal deste projeto é consolidar fundamentos da linguagem, **lógica de programação**, **algoritmos** e tratamento correto de **entrada/saída de dados**.

---

## 📁 Estrutura e Padronização do Repositório

Para manter o repositório escalável e adaptado aos requisitos do Beecrowd, cada arquivo contém:

1. **A Classe Principal (`Main`):** Estrutura padrão exigida pela plataforma para submissão dos problemas em Java.
2. **Leitura e Saída de Dados:** Configuração pronta com leitores de entrada (ex: `Scanner` ou `BufferedReader`) para testar diretamente na sua IDE.

Os arquivos estão organizados em diretórios com base na numeração dos exercícios ou categorias:

```text
├── src/
│   ├── iniciante/
│   ├── ad_hoc/
│   └── estruturas/
└── README.md
```

---

## ⚙️ Como Executar os Testes na IDE

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com/lxzinxs/beecrowd
   ```

2. **Abrir o Projeto:**
   * Importe a pasta do repositório na sua IDE de preferência (**IntelliJ IDEA**, **Eclipse** ou **VS Code**).
   * Verifique se o **JDK** está configurado no ambiente.

3. **Executar um Exercício:**
   * Navegue até a classe do problema correspondente.
   * Execute o método `main` fornecendo os dados de entrada via console para validar a saída.
